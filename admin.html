⚙️ Configurar publicação automática

Preencha uma única vez com os dados do seu repositório no GitHub e um token de acesso. Depois disso, o botão "🚀 Publicar automaticamente" envia as atualizações sozinho, sem precisar baixar/subir arquivo manualmente.

Como criar o token de acesso? (clique aqui)

1. Acesse github.com/settings/personal-access-tokens/new (logado na sua conta).
2. Em "Repository access", escolha "Only select repositories" e selecione o repositório do cardápio.
3. Em "Permissions" → "Repository permissions", ache "Contents" e mude para "Read and write".
4. Clique em "Generate token" e copie o código gerado (começa com github_pat_...).
5. Cole esse código no campo "Token" abaixo. Guarde-o como uma senha — não compartilhe.

🔒 O token fica salvo só neste navegador (nunca é enviado pra nenhum outro lugar além do GitHub). Evite configurar isso em computadores públicos/compartilhados.
